# Pitch and demo coach

- H1: What is the one-sentence pitch, and which problem does it show?
- H2: What does the 2 to 3 minute demo show, step by step? Build only what the demo shows.
- H3: Which parts can be faked for the demo (sample data, a fixed login) without lying about what works?
- H4: At which hour is the demo frozen, leaving time to rehearse?
- H5: What is the backup if the network or a service fails during the demo (a recording, local data)?
- H6: What do the judges score, and does the plan aim at it?
