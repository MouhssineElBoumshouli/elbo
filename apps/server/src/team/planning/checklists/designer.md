# Designer

- D1: Who is the main user, and on which device (phone, laptop, projector)?
- D2: What are the 3 to 5 main screens, and what does each one do?
- D3: What is the main path a user takes, in as few steps as possible?
- D4: What does each screen show when empty, loading, or when something fails?
- D5: Is the text large enough, is the contrast high enough, and does it work with a keyboard?
- D6: Does the look match the "feel" answer in the brief?
- D7: Which screens can reuse the same layout, so there is less to build?
- D8: Does any idea in the brief make it hard to use? Push back with a better option.
